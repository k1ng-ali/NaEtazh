# StroyBaza97

Интернет-магазин стройматериалов с доставкой и подъёмом в квартиру. Запуск 20 ноября 2026.

Магазин называется «Строй База» (StroyBaza), домен `stroybaza97.ru`. Как выбирали — в
[плане](docs/plan.md#название-и-домен).

## Стек

Nuxt 4 + Vue 3, FastAPI, PostgreSQL 16, Docker Compose, GitHub Actions, Docker Hub.

## Запуск

```bash
cp .env.example .env
docker compose up --build
docker compose exec backend python -m scripts.seed_demo
```

- Сайт: http://localhost:3000
- Вход для сотрудников: http://localhost:3000/login. Демо-владельца, менеджера и курьера
  создаёт `scripts/seed_demo.py`, логины и пароль в начале файла
- API и документация: http://localhost:8000/docs

Перед первым запуском замените значения в `.env`.

Сервер, релизы, резервные копии — в [deploy/README.md](deploy/README.md).

## Кабинеты сотрудников

Вход у всех один, после него каждый попадает в свой кабинет:

| Роль | Кабинет | Что может |
|---|---|---|
| `admin` — владелец | `/admin` | Сводка, деньги заказов, наценка, дома и тарифы, услуги и их цены, сотрудники, плюс всё, что менеджер |
| `manager` — менеджер | `/manager` | Заказы, заявки на услуги, назначение курьера и даты, каталог, остатки, партнёр. Без прибыли |
| `courier` — курьер | `/courier` | Только назначенные ему доставки: выехал, доставлен с суммой, проблема |

Первого владельца на сервере создаёт скрипт, пароль спрашивается в терминале. Остальных
сотрудников владелец добавляет в разделе «Сотрудники».

```bash
docker compose exec backend python -m scripts.create_user --login owner --name "Имя" --role admin
```

## Услуги

Страница `/services` и блок «Услуги» на главной. Покупатель оставляет заявку: имя, телефон,
адрес или корпус из QR, удобный день, что сделать. Заявка приходит менеджеру в раздел
«Заявки», в Telegram уходит без имени и телефона. Список услуг, тексты и цены владелец меняет
в разделе «Услуги»; пустая цена на сайте — «Цену назовём после звонка». Там же общий телефон
для кнопки «Позвонить» и, если нужно, свой телефон у отдельной услуги. Пока телефона нет,
кнопки нет.

## Импорт партнёра

Выгрузку партнёра можно обновить кнопкой в разделе «Партнёр» или скриптом. Тумблер «Товары
партнёра на витрине» там же заводит товар на каждое предложение, разделы как у партнёра.
Покупатель видит только то, что есть в наличии и с наценкой. На сервере скрипт запускает cron
раз в час, он же докачивает фото:

```cron
0 * * * * cd ~/stroybaza97/deploy && docker compose -f docker-compose.prod.yml exec -T backend python -m scripts.sync_suppliers
```

## Проверки без Docker

Бэкенд:

```bash
cd backend
uv venv --python 3.12
uv pip install -r requirements.txt -r requirements-dev.txt
uv run --no-sync ruff check .
uv run --no-sync pytest
```

Фронтенд:

```bash
cd frontend
npm ci
npm run typecheck
npm run build
```

## Ветки и выпуск

- `main` — основная ветка.
- `release` или тег `v*` — сборка и публикация образов в Docker Hub.

В настройках GitHub нужны секреты `DOCKERHUB_USERNAME` и `DOCKERHUB_TOKEN`.
На сервере обновление выполняет `deploy/update.sh`.
