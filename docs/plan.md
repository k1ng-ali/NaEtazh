# План до запуска 20 ноября 2026

Оценка: 130–170 часов при работе одного разработчика с ИИ-агентом.

## Этапы

| Даты | Этап | Готово, когда |
|---|---|---|
| 2–4 ноября | Основа | Каркас работает, домен куплен, срок визиток известен, вопросы партнёру отправлены |
| 4–9 ноября | Каталог и админка | Вход менеджера, товары и цены, импорт выгрузки, наценки, сопоставление |
| 9–13 ноября | Заказ | Корзина, доставка и подъём, распределение по источникам, статус, уведомления |
| 13–16 ноября | Наполнение | Настоящие товары и фото, юридические страницы, Метрика, мобильная полировка |
| 17–19 ноября | Проверка | Сервер и HTTPS, тест с 5 пользователями, заказ до реальной квартиры |
| 20 ноября | Запуск | Визитки ведут на сайт, менеджер получает заказы |

## Ближайшие задачи

### Основа
- [x] Концепция, архитектура и план
- [x] Каркас FastAPI, модели, первая миграция, API каталога
- [x] Каркас Nuxt, токены дизайна, первый экран и каталог
- [x] Docker Compose, CI и публикация образов
- [ ] Создать репозиторий на GitHub и подключить секреты
- [ ] Проверить полный запуск в Docker
- [ ] Купить домен, настроить короткие редиректы для QR

### Каталог и админка
- [ ] Пользователи и вход менеджера (JWT, httpOnly refresh-cookie)
- [ ] CRUD категорий, товаров, характеристик и остатков
- [ ] Загрузка и сжатие фото
- [ ] Импорт YML партнёра с защитой от сбоев
- [ ] Сопоставление предложений и правила наценки с минимальной прибылью

### Заказ
- [ ] Страница ЖК, определение корпуса по QR
- [ ] Страница товара и калькулятор расхода
- [ ] Корзина с сохранением при обрыве связи и ссылкой «отправить мастеру»
- [ ] Тарифы доставки и подъёма, окна с лимитом заказов
- [ ] Распределение заказа: сначала склад, затем партнёр
- [ ] Оформление, статус по токену, уведомление в Telegram
- [ ] Этапы заказа, себестоимость и прибыль в админке

### Перед запуском
- [ ] Политика данных, согласие, cookie-баннер, условия возврата
- [ ] Метрика и события воронки по корпусам
- [ ] Резервные копии БД и мониторинг
- [ ] Прогон заказа от QR до доставки

## Риски

| Риск | Что делаем |
|---|---|
| Партнёр не подписал условия к 9 ноября | Запуск с ручными заказами и примерным наличием |
| Визитки печатаются раньше готовности сайта | QR ведёт на короткий адрес с редиректом, его можно менять |
| Нет настоящих тарифов | Админка хранит тарифы, значения вносит клиент |
| Каталог не наполнен | Старт с самых ходовых товаров, наполнение назначено на сотрудника клиента |
| Отказ при доставке за наличные | Подтверждение по телефону, предоплата для крупных заказов |
